# Part 2 Testing Checklist

Use Microsoft Edge Developer Tools (F12) and test the website at:
- Desktop: approximately 1366px wide
- Tablet: approximately 768px wide
- Mobile: approximately 480px wide

Check:
- All five navigation links open the correct page.
- No horizontal scrolling occurs at tablet/mobile widths.
- Navigation changes to a vertical layout at smaller widths.
- Service cards change from two columns to one column.
- Images scale without overflowing.
- Video and maps remain responsive.
- Form controls fit within the screen.
- Hover, focus and active states are visible.
- The website remains readable at each breakpoint.

Take screenshots of desktop, tablet and mobile views and add them to the README if required by the lecturer.
